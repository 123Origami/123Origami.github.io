Cloud and DevOps skills are built by doing, not just reading. This repository is where that happens: a growing collection of project-based labs completed under StegHub, each one tackling a different piece of the DevOps toolchain end to end.

The projects span Linux server administration and classic web stack deployments (LAMP, LEMP, MEAN), configuration management and continuous integration with Jenkins and Ansible, and AWS cloud infrastructure provisioned and managed as code with Terraform. Each project is documented as it's completed, building toward a practical, hands-on foundation in cloud engineering.

This is an ongoing body of work rather than a single finished product — new projects are added as I work through the curriculum, each one documented in its own numbered folder in the repo.
